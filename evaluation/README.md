# Evaluation

User studies, offline benchmarks, and reporting — kept separate from implementation code.

## Purpose

House datasets, annotations, experiment configs, metrics definitions, and written reports for the FYP evaluation.

## Layout

| Path | Role |
|------|------|
| `datasets/` | Evaluation datasets |
| `annotations/` | Study annotations / labels |
| `experiments/` | Experiment definitions |
| `metrics/` | Metric definitions / scripts |
| `reports/` | Generated or written reports |

## Note

ML training-time evaluation helpers may live under `/ml/evaluation`. This folder is for the overall system / human evaluation track.
